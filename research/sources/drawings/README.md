# Заводские чертежи ЗИЛ-130 и ЗИЛ-131

Самих чертежей в репозитории нет: они куплены в магазине [autoar.org](https://autoar.org/). В git лежат только этот файл и превью: рядом с каждым листом `*.preview.jpg`, 1600 px по длинной стороне. По превью видна компоновка листа, но размеры с него не снять. Каталоги ниже повторяют разделы магазина. Чтобы ссылки из `research/engine-data.md` (`[HD87 л.2 вид И]`, `[BD л.1 вид сверху]`) работали, купите нужные листы и положите их по этим путям.

**Нет российской карты и купить не получается?** Напишите автору репозитория — дам ссылку на свой Яндекс Диск, там лежит всё купленное.
