# Библиотека источников

Всё, на что опираются расчёты, модели и исследования проекта. Каждая цифра в тексте ссылается сюда шифром и страницей: `[D73 дж.53]` — книга D73, страница 53 файла DjVu, `[HD87 л.2 вид И]` — лист 2 чертежа головки.

Файлы книг и даташитов лежат в релизе [`sources`](https://github.com/jidckii/zil_130/releases/tag/sources) на GitHub и скачиваются по прямым ссылкам. В git их нет, в репозитории только постраничный текст для поиска — `research/sources/ocr/<имя>.txt`. Права на книги, руководства и каталоги принадлежат их правообладателям. Мы собрали их из открытых архивов, откуда каждая взята — в колонке «Откуда». Почти всё найдено в репозитории Genofond НТУ «Днепровская политехника».
