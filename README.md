# ЗИЛ-130 и ЗИЛ-131 на впрыске

Открытый проект: недорогой и повторяемый перевод V8 ЗИЛ (6,0 л, по возможности и 7,0 л ЗИЛ-375) с карбюратора или газового смесителя на распределённый впрыск метана с электронным зажиганием — с турбонаддувом и без.

**Сайт проекта: https://jidckii.github.io/zil_130/** — манифест, варианты переделки, что готово, как помочь.

![Модель впускного коллектора: плита развала и ресивер](docs-site/static/img/renders/intake-iso-front.png)

## Принципы

- **Родной двигатель.** Блок не трогаем: меняем впуск, зажигание и управление, по желанию — головки и наддув.
- **Серийные покупные узлы**: газовые форсунки и редуктор, дроссель ЗМЗ-406, открытый ЭБУ rusEFI. Сами делаем только коллектор, плиту, кронштейны, шкив с кольцом 60-2.
- **Поэтапно и обратимо**: 1–2 дня простоя на этап, штатные узлы сохраняются. Приоритет — момент на низах и экономичность, обороты заводские.
- **У каждой цифры есть источник** — заводские чертежи и книги.

## Этапы

| Этап | Что делаем |
|---|---|
| 0. Подготовка | Журнал расхода, закупка, сборка и проверка ЭБУ на столе |
| 1. Электронное зажигание | Шкив с кольцом 60-2, датчики, катушки; газ пока через смеситель |
| 2. Распределённый впрыск | Свой коллектор (плита развала + ресивер), дроссель ЗМЗ-406, редуктор и форсунки |
| 3. Головки | Фрезеровка под ε 8–8,5, сёдла и пружины под газ |
| 3а. Охлаждение и навесное | Радиатор, маслорадиаторы, вискомуфта, генератор, компрессор |
| 4. Наддув | Две турбины по одной на ряд, интеркулер, +0,3…0,5 бар |

Подробно, с простоем и откатом по каждому этапу, — [docs/plan.md](docs/plan.md). Там же раздел «Продолжить отсюда»: принятые решения и следующие шаги.

## Запуск

```bash
uv run python calc/intake_sizing.py   # расчёты → calc/results.md
uv run python cad/receiver.py         # модель коллектора → cad/out/, падает при нарушении зазоров
lua ecu/zil130_test.lua               # проверка Lua-скрипта ЭБУ
cd docs-site && yarn && yarn start    # сайт локально
```
