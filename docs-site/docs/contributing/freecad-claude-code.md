# FreeCAD и Claude Code

Модели в проекте — это Python-скрипты на [build123d](https://build123d.readthedocs.io/). Исходник — скрипт, FreeCAD нужен, чтобы смотреть, мерить и рендерить. Изменения, сделанные мышкой в FreeCAD, в проект не попадут: правьте скрипт в `cad/`.

Бо́льшую часть работы удобно делать вместе с [Claude Code](https://claude.com/product/claude-code) — ИИ-ассистентом, который работает в терминале, читает репозиторий и через MCP управляет FreeCAD и CAD-сессией build123d. Он не обязателен: всё то же самое делается руками по разделу [«Окружение»](/docs/contributing/environment).

![Claude Code правит скрипт разрезки плиты под стол 3D-принтера](/img/contributing/claude-code-session.png)

## FreeCAD и аддон MCP

Аддон [FreeCAD MCP](https://github.com/neka-nat/freecad-mcp) поднимает внутри FreeCAD RPC-сервер на `127.0.0.1:9875`. Через него Claude Code открывает модели, крутит вид, меряет и делает снимки.

1. Поставьте FreeCAD 1.1.
2. Скопируйте каталог `addon/FreeCADMCP` из репозитория аддона в каталог модулей FreeCAD:
   - Linux: `~/.local/share/FreeCAD/v1-1/Mod/`;
   - Windows: `%APPDATA%\FreeCAD\v1-1\Mod\`;
   - macOS: `~/Library/Application Support/FreeCAD/v1-1/Mod/`.
3. Перезапустите FreeCAD и выберите верстак **MCP Addon**.
4. Нажмите **Start RPC Server** и включите **Auto-Start Server**, чтобы сервер поднимался сам при каждом запуске.

![FreeCAD с верстаком MCP Addon: кнопки Start RPC Server и Auto-Start Server](/img/contributing/freecad-mcp-addon.png)

Версию аддона держите такой же, как у MCP-сервера в `.mcp.json` (сейчас 0.1.25). Если они разойдутся, инструмент `get_rpc_status` об этом скажет.

## Claude Code

1. Поставьте Claude Code по [инструкции](https://code.claude.com/docs/en/setup) и войдите в свою учётную запись.
2. Поставьте `uv` — через него запускаются MCP-серверы.
3. Запустите `claude` в корне репозитория. На первом запуске он спросит, доверяете ли вы этой папке, — подтвердите. После этого MCP-серверы проекта подключатся сами: они одобрены в `.claude/settings.json`.

В `.mcp.json` уже описаны два сервера, отдельно ставить их не нужно, `uvx` скачает их сам:

| Сервер | Что даёт |
|---|---|
| `freecad` (freecad-mcp) | Живой FreeCAD: открыть STEP, повернуть вид, измерить, сохранить картинку |
| `build123d` (build123d-mcp) | Постоянная CAD-сессия: строить по шагам, мерить объём и зазоры, сравнивать варианты, экспорт STEP/STL |

Что Claude Code получает из репозитория:

- `CLAUDE.md` — структура проекта, правила данных, инструменты. Читается автоматически;
- `.claude/settings.json` — одобренные MCP-серверы и разрешения на типовые команды проекта: расчёты, модели, тест ЭБУ, сборку сайта. Свои настройки кладите в `.claude/settings.local.json`, он в git не попадает;
- `.claude/skills/b123d-*` — навыки для моделирования, правки и ремонта моделей build123d;
- `docs/plan.md`, раздел «Продолжить отсюда» — принятые решения и следующие шаги. С него стоит начинать каждую сессию.

## Как работать

Пишите задачу обычным языком. Хорошая задача называет деталь, цель и способ проверки:

```text
Прочитай docs/plan.md. Добавь на ресивер посадочное место регулятора
холостого хода от ЗМЗ-406 и проверь, что ключ проходит ко всем болтам.
```

```text
В engine-data.md найди толщину прокладки ГБЦ по заводским книгам.
Каждую цифру — со ссылкой на документ и страницу.
```

```text
Открой cad/out/intake_assembly.step в FreeCAD и покажи зазор
от ресивера до клапанных крышек.
```

Перед pull request проверьте, что сделал ассистент:

- у новых цифр есть ссылки на источник, оценки помечены;
- скрипты в `cad/` и `calc/` запускаются, а проверки в них проходят;
- `calc/results.md` пересобран скриптом, а не поправлен руками.
