# ЗИЛ-130: модернизация V8

Хобби-проект: V8 ЗИЛ-130 (6,0 л, 100×95) и по возможности ЗИЛ-375 (7,0 л, 108×95) —
распределённый впрыск только метана, свой впускной коллектор; два варианта — атмосферный и с наддувом 0,3–0,5 бар. Открытый общественный проект, комплект ставится целиком.
Концепция — `docs/project.md`: перенесена из Google Doc «Зил-130_Проект_Модернизации»,
основная версия теперь здесь, с Google Drive не синхронизируем.

## Структура

- `docs/` — концепция, варианты и состав комплекта (`project.md`), порядок работ и бэклог (`plan.md`); смета — `research/parts-list.md`.
- `calc/` — расчёты на Python; `results.md` генерируется скриптом, руками не править.
- `ecu/` — настройки rusEFI и Lua-скрипт; проверка — `lua ecu/zil130_test.lua`.
- `cad/` — модели на build123d: плита развала, ресивер, разрезка под печать; выход в `cad/out/` (в git не попадает).
  Проверки зазоров и доступа ключом — в самих скриптах, `uv run python cad/receiver.py` падает при нарушении.
- `research/engine-data.md` — заводские данные двигателя, у каждой цифры ссылка `[документ стр.]`.
- `research/prior-art.md` — чужие переделки, рынок, ЭБУ.
- `research/videos/notes.md` — разбор видео Pshenitsin_v8 inc.; кадры в `keyframes/`.
- `research/sources/drawings/` — купленные заводские чертежи по разделам autoar.org, `README.md` со ссылками на магазин; копия — Яндекс Диск `zil_130/` с той же структурой.
- `docs-site/` — сайт на Docusaurus, публикуется на GitHub Pages из `main` (`.github/workflows/docs.yml`).
  Раздел «Исследования и расчёты» собирается из `docs/plan.md`, `research/`, `calc/`, `ecu/` как есть;
  проверка — `cd docs-site && yarn build` (битые ссылки ломают сборку).
- `research/sources/` — сканы заводских книг (DjVu/PDF, в git не попадают),
  `ocr/*.txt` — постраничный текст для grep, `figures/` — страницы с чертежами.

## Правила данных

- Геометрию берём из заводской документации, 3D-скан не делаем.
- Каждая цифра в расчётах и CAD — со ссылкой на источник; неизвестное помечать, не выдумывать.
- Параметры, которые отличаются у 6,0 и 7,0 л, держать параметрами, а не константами.
- Поиск информации о двигателе — прежде всего в русскоязычных источниках.
- Готовые узлы — массовые, недорогие, проверенные, в наличии у многих продавцов РФ; не под заказ и не редкие.
  Дорогое — только если дешёвой альтернативы нет, и с обоснованием: кит должен быть по карману владельцу ЗИЛа.
- Цены и сметы — в долларах США. В `research/` цена остаётся как у продавца (₽, драм, €), в долларах — в `research/parts-list.md`
  и `docs/`; курсы ЦБ РФ с датой — в шапке `research/parts-list.md`, при пересчёте обновлять их там.

## Инструменты

- Python: `uv run python ...` (build123d, Cantera, CoolProp, numpy/scipy/matplotlib).
- MCP `freecad` — живой FreeCAD 1.1 (RPC на 127.0.0.1:9875, автозапуск включён в аддоне).
- MCP `build123d` + скиллы `b123d-*` — CAD кодом, экспорт STEP/STL.
- Сканы: `djvutxt`/`ddjvu`, `pdftotext`/`pdftoppm`, `ocrmypdf -l rus`.
- Видео: `uvx --from 'yt-dlp[default]' yt-dlp --js-runtimes node` (системный yt-dlp ловит 403).
